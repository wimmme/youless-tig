# Grafana: data source and dashboard

The complete stack ([stack.md](stack.md)) sets up the data source and the
dashboard by itself. These steps are for your own Grafana.

## Data source

The dashboard uses **InfluxQL**, which works with InfluxDB 2 through a token.

*Connections → Data sources → Add data source → InfluxDB*:

| Setting | Value |
|---|---|
| Query language | InfluxQL |
| URL | `http://<influxdb>:8086` |
| Custom HTTP Headers | Header `Authorization`, value `Token <a read-only token for the bucket>` |
| Database | the bucket name, e.g. `youless` |
| HTTP Method | POST |

*Save & test* should say the data source is working. A read-only token is
enough: [influxdb.md](influxdb.md#token).

## Dashboard

*Dashboards → New → Import*, upload
[`grafana/dashboards/youless.json`](../grafana/dashboards/youless.json) and pick
the data source. The dashboard has three variables at the top:

- **Data source**: the InfluxDB data source.
- **YouLess**: the `device` tag, for more than one YouLess in a bucket.
- **Time zone (daily totals)**: used to cut days for *Import and export per day*;
  set it to your time zone.

| Row | Panels |
|---|---|
| Now | power now, import, export, gas and water today, capacity peak this month (Belgium) |
| Power | net power, power per phase, voltage, current |
| History | electricity per day and per hour, import and export per day, gas and water per day, the long-term minute log |

The history panels have their own time ranges (7, 30 or 90 days, shown in the
panel title bar); the others follow the dashboard's time picker.

## Your own panels

Measurements, fields and units are in [data-model.md](data-model.md), with
example queries. A few tips:

- Day totals from the device are in `youless_log` with `resolution = 'day'`,
  one point per day at local midnight: show them as bars without `GROUP BY`.
- For consumption over any period from the meter readings, use `spread()` of
  the `import_*` and `export_*` counters, with `tz('Europe/Brussels')` when
  grouping by day.
- The dashboard is generated by [`tools/dashboard/gen.py`](../tools/dashboard/gen.py);
  change that and regenerate if you want to contribute a change.
